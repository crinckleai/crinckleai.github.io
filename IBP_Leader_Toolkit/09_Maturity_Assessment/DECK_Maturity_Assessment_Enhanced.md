# ANIMATION SPECIFICATIONS

## Slide Transitions
| Transition | Type | Duration |
|------------|------|----------|
| Title | Mountain reveal | 1.0s |
| Assessment slides | Smooth fade | 0.6s |
| Deep dives | Push up | 0.5s |
| Roadmap | Path draw | 0.8s |
| Closing | Zoom to center | 0.7s |

## Element Animations
| Element | Animation | Trigger |
|---------|-----------|---------|
| Maturity gauge | Fill + pointer sweep | On appear |
| Radar chart | Sweep draw | Sequential axes |
| Progress bars | Grow left to right | Staggered |
| Staircase | Step reveal | Bottom to top |
| Roadmap path | Line draw | Left to right |

| Level | Color | Emotion |
|-------|-------|---------|
| Level 1 | Red | Urgency, need for action |
| Level 2 | Orange | Developing, potential |
| Level 3 | Yellow | Integrated, functioning |
| Level 4 | Green | Advanced, confident |
| Level 5 | Teal | Leading, excellence |
