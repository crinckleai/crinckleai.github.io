# ANIMATION SPECIFICATIONS

## Slide Transitions
| Transition | Type | Duration |
|------------|------|----------|
| Title to Content | Morph | 0.7s |
| Content slides | Push Left | 0.5s |
| Section change | Fade + Zoom | 0.8s |

## Element Animations
| Element | Animation | Trigger |
|---------|-----------|---------|
| KPI gauges | Fill + glow | On appear |
| Capacity bars | Grow from left | Sequential |
| Constraint bubbles | Pop + pulse | Staggered |
| Radar chart | Sweep draw | On appear |
| Decision buttons | Subtle pulse | Continuous |

## Interactive Elements
- Hover states on all clickable items
- Drill-down capability on charts
- Scenario toggle buttons
- Collapsible detail sections
