# ANIMATION GUIDE

## Slide Transitions
- **Recommended:** Morph (PowerPoint) / Magic Move (Keynote)
- **Alternative:** Fade with 0.5s duration
- **Avoid:** Spins, flips, or flashy transitions

## Element Animations

| Element | Animation | Timing |
|---------|-----------|--------|
| Titles | Fade Up | On load, 0.3s |
| Cards | Staggered Fade In | 0.1s delay each |
| Metrics | Count Up | 1.5s duration |
| Charts | Draw/Grow | 1s duration |
| Icons | Pop/Scale | 0.2s with bounce |
| Arrows | Line draw | 0.5s |
| Progress bars | Fill left-to-right | 1s |

## Interactive Elements
- Hover states on all cards
- Click to reveal additional information
- Zoom on metrics for detail view

# POWERPOINT IMPLEMENTATION TIPS

1. **Use the Slide Master** - Set up all colors, fonts, and layouts once

2. **Create Custom Shapes** - Use Shape Format > Merge Shapes for unique elements

3. **Morph Transitions** - Duplicate slides and modify for smooth animations

4. **Charts** - Use built-in chart animations, set to "By Series" for impact

5. **Gradient Fills** - Edit shape > Format > Gradient Fill for professional look

6. **Icons** - Insert > Icons in modern PowerPoint versions

7. **Alignment** - Use View > Guides and Snap to Grid

8. **Export** - Consider animated GIF export for web sharing
