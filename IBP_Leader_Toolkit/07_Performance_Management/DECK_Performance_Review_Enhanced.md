# ANIMATION SPECIFICATIONS

## Slide Transitions
| Transition | Type | Duration |
|------------|------|----------|
| Title to Content | Dynamic reveal | 0.8s |
| Content slides | Slide left | 0.5s |
| Performance views | Morph | 0.6s |
| Closing | Zoom | 0.7s |

## Element Animations
| Element | Animation | Trigger |
|---------|-----------|---------|
| Score gauges | Fill with count | On appear |
| Progress bars | Grow right | Sequential |
| Trend lines | Path draw | Left to right |
| Benchmark markers | Drop in | Staggered |
| Tables | Row fade | Top to bottom |

## Color Coding Standards
| Score Range | Color | Status |
|-------------|-------|--------|
| 90-100 | Gold #FFD700 | Exceptional |
| 80-89 | Green #00E676 | On Target |
| 70-79 | Blue #2196F3 | Progressing |
| 60-69 | Orange #FF9100 | Below Target |
| <60 | Red #FF1744 | Critical |
