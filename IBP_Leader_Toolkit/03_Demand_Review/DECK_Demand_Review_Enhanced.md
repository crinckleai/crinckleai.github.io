# ANIMATION SPECIFICATIONS

## Chart Animations
| Chart Type | Animation | Timing |
|------------|-----------|--------|
| Gauges | Needle sweep | 1s ease-out |
| Heat map | Cells fade in | 0.05s staggered |
| Waterfall | Bars grow sequential | 0.2s each |
| Line chart | Path draw | 2s |
| Bar charts | Grow from zero | 1s |

## Transitions
- **Between slides:** Morph or smooth fade
- **Build animations:** Fade up with subtle movement
