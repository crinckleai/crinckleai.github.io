## How to Use This Toolkit

### PowerPoint Decks (DECK_*.md files)
- Each deck file contains slide-by-slide content outlines
- Copy content into your corporate PowerPoint template
- Customize data, charts, and visuals as needed
- Speaker notes included for key slides

### Excel Templates (*.csv files)
- Import CSV files directly into Excel
- Apply corporate formatting and branding
- Connect to data sources as appropriate
- Formulas and conditional formatting instructions included in comments

## Monthly IBP Cycle Usage

| Week | Activity | Key Templates |
|------|----------|---------------|
| Week 1 | Product Review | 02_Product_Review/* |
| Week 2 | Demand Review | 03_Demand_Review/* |
| Week 3 | Supply Review | 04_Supply_Review/* |
| Week 4 | Financial & Executive Review | 05_Financial_Review/*, 06_Executive_IBP/* |

## Quick Start Guide

1. **New IBP Implementation**: Start with `01_IBP_Governance/` and `08_Change_Management/`
2. **Running Monthly Cycle**: Use folders 02-06 in sequence each month
3. **Performance Reviews**: Use `07_Performance_Management/` quarterly
4. **Maturity Assessment**: Use `09_Maturity_Assessment/` annually
